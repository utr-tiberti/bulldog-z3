# Bulldog Z3

Videogioco a piattaforme in stile fumetto: il bulldog supereroe spara frese Z3 nel magazzino utensili e affronta il robot ROBO-X9.

**Gioca:** https://utr-tiberti.github.io/bulldog-z3/

Sul telefono: apri il link, gira in orizzontale; per averlo come app usa "Aggiungi alla schermata Home" (Safari: Condividi). Dopo la prima apertura funziona anche senza rete.
Tastiera: frecce o A/D cammina, Spazio salta, giu abbassati, X spara, P pausa, M audio.
